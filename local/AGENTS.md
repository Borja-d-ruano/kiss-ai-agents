# Guía para quien edite este código

## Antes de codificar

1. Leer [`analisis-docs/KISS_agents-analisis-y-propuesta.md`](../../analisis-docs/KISS_agents-analisis-y-propuesta.md) (obligatorio).
2. Releer [`docs/philosophy.md`](docs/philosophy.md) y [`docs/contracts.md`](docs/contracts.md).

## Convenciones

- Python **solo stdlib**.
- Sin añadir dependencias pip salvo decisión explícita y ADR.
- Nuevas features preferiblemente como **contenido markdown** o como filas en `schedule.md`, no como tablas nuevas en BBDD.
